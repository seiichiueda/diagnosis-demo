━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 開き方
  1. ZIP ファイルを右クリック →「すべて展開」でフォルダに展開します。
     ※ ZIP を開いただけの状態で manual.html を開くと、動画や説明文が表示されません。
  2. 展開したフォルダの中の manual.html をダブルクリックします。
     （Chrome または Edge で開いてください。インターネット接続は不要です）
  ※ manual.html だけを取り出して開いても、標準の説明文と見本アニメで動きます。
     実際の操作動画や書き換えた説明文を使うには、steps.js と videos フォルダを同じ場所に置いてください。

■ フォルダの中身
  manual.html … マニュアル本体（通常は触りません）
  steps.js    … タイトル・説明文・動画ファイル名（メモ帳で編集できます）
  videos\     … 各ステップの操作動画（MP4）
  README.txt  … このファイル

■ 動画を差し替えたいとき
  videos フォルダの中の動画を、「同じファイル名」の新しい動画で上書きします。
  manual.html を開き直せば反映されます。
    例）videos\01_login.mp4 を、実際に録画した動画で上書き
  ・動画の形式は MP4 にしてください。
  ・ファイル名を変えたい場合は、steps.js の video: '…' の部分も同じ名前に直してください。
  ・ファイル名は半角英数字にしておくと、ZIP でやり取りしても文字化けしません。
  ・動画が見つからないステップでは、代わりに「見本アニメ」が表示されます。

■ 説明文を直したいとき
  steps.js をメモ帳で開き、'…' の中の文章を書き換えて保存します。
  ・保存するときの文字コードは「UTF-8」にしてください（メモ帳の標準設定のままでOK）。
  ・' （半角のシングルクォート）や , （カンマ）を消さないよう注意してください。
  ・書き方を間違えると「steps.js を読み込めませんでした」と表示されます。
    その場合は、直前に編集した箇所を見直してください。

■ 動画の上に字幕を出したいとき（任意）
  steps.js の各ステップに、次のように秒数と文章を書き足します。
    captions: [
      { at: 1.5, text: '社員IDを入力します' },
      { at: 4.0, text: '「ログイン」を押します' }
    ],

■ ステップを増やす／減らすとき
  steps.js の { から }, までの1ブロックをコピーして追加、または削除します。
  動画は videos フォルダに追加してください。

■ 印刷
  ・「全ステップを印刷」… 表紙・目次と、全ステップ（1ステップ1ページ）
  ・「このステップを印刷」… 表示中のステップだけ
  印刷画面で送信先を「PDF に保存」にすると PDF にもできます。
  各ページの画面は、動画の最後の場面が使われます（steps.js の printAt: 秒数 で変更可）。

■ 配り直すとき
  フォルダを右クリック →「送る」→「圧縮 (zip 形式) フォルダー」で ZIP にして配布します。
